# gator

A CLI RSS feed aggregator written in Go. A long-running scraper collects posts from RSS feeds into PostgreSQL, and you browse the latest posts from the feeds you follow. Queries are type-safe Go generated by sqlc, and the schema is versioned with goose migrations.

## How it works

- **Feed rotation:** each tick, the scraper fetches the feed that was fetched longest ago, so feeds take turns without a separate scheduler.
- **Deduplication:** post URLs are unique, so scraping the same feed again only stores new posts.
- **Time zones:** publish dates in several RSS formats are parsed and stored in UTC, so posts from different feeds sort correctly.
- **Auth middleware:** commands that need a user are wrapped in a middleware that loads the logged-in user from the config.
- **Cascading deletes:** foreign keys cascade, so deleting a user removes their feeds, follows and posts.

## Requirements

- Go 1.25+
- PostgreSQL
- [goose](https://github.com/pressly/goose) for running migrations

## Install

```bash
go install github.com/jpsilvadev/gator@latest
```

Or build from source:

```bash
git clone https://github.com/jpsilvadev/gator.git
cd gator
go build -o gator .
```

## Setup

1. Create a database:

   ```bash
   createdb gator
   ```

2. Create `~/.gatorconfig.json`:

   ```json
   {
     "db_url": "postgres://USER:PASS@localhost:5432/gator?sslmode=disable"
   }
   ```

3. Run the migrations:

   ```bash
   cd sql/schema
   goose postgres "postgres://USER:PASS@localhost:5432/gator" up
   ```

## Usage

```bash
gator <command> [args...]
```

### Users

| Command | Description |
| --- | --- |
| `register <name>` | Create a user and log in as them |
| `login <name>` | Switch to an existing user |
| `users` | List all users |

### Feeds

| Command | Description |
| --- | --- |
| `addfeed <name> <url>` | Add a feed and follow it |
| `feeds` | List all feeds |
| `follow <url>` | Follow an existing feed |
| `unfollow <url>` | Unfollow a feed |
| `following` | List the feeds you follow |

### Posts

| Command | Description |
| --- | --- |
| `agg <interval>` | Scrape feeds continuously, one feed per tick (e.g. `30s`, `1m`). |
| `browse [limit]` | Show the newest posts from feeds you follow (default 2) |

### Other

| Command | Description |
| --- | --- |
| `reset` | Delete all users and their data |

## Example

```bash
gator register user
gator addfeed "NASA" "https://www.nasa.gov/news-release/feed/"
gator agg 30s        # leave running in another terminal
gator browse 2
```

A second user can follow a feed someone else added, and `following` lists what they follow. `register` also logs you in as the new user:

```bash
gator register user2
gator follow "https://www.nasa.gov/news-release/feed/"
gator following
```
